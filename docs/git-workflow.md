# Git workflow

## Mục tiêu
Repo này minh họa một workflow cơ bản nhưng sạch:
1. Tách từng phần việc ra branch riêng.
2. Commit message theo Conventional Commits.
3. Tên branch mô tả đúng mục đích.
4. Merge lần lượt về `develop`, sau đó về `main`.

## Danh sách branch
1. `main`
2. `develop`
3. `feature/base-structure`
4. `feature/ui-styling`
5. `feature/greeting-toggle`
6. `docs/project-guide`

## Gợi ý đặt tên branch
- Tính năng: `feature/<ten-tinh-nang>`
- Sửa lỗi: `fix/<ten-loi>`
- Tài liệu: `docs/<noi-dung>`
- Việc hệ thống: `chore/<noi-dung>`
